# M2検証記録

実施日: 2026-11-16（日本時間）。仕様14のM2を対象。構造と工程を同じ優先度で実装し、M3以降の出力・探索には進まない。追加依存なし。

## 計算と実行

- `npm run check`: strict型検査、7ファイル149テスト、本番ビルドが合格。既存M0/M1の111テストも維持。
- 構造: mean Sからの距離、規模重み付き平均連結、1e-12のtie-break、全併合履歴とk切断、元index所属・クラスタ連続順。F07はk=2で所属{A,B}/{C,D}、調整コスト4、外部重み0。
- 工程: 非再帰Tarjan、重複除去した縮約DAG、最小元index優先Kahn、最長先行Band。F01〜F10のSCC/Band期待値と一致。SCC内部は元順。F09で最適値2を返すとは要求せず、元順のF=5を確認。
- 比較基準: 構造の全一群／全単要素、工程のIdentity。最適化手法とは別に表示する。
- 結果のモード・入力ハッシュ・前処理・指標版・αによる比較条件を検査し、異条件を順位付けしない。kはアルゴリズム設定として、同一目的関数の異なるkと基準解を比較可能とする。
- 完了結果と元行列を変更せず、別のViewHistoryで並べ替え。undo/redo後の値を照合。工程は現在ビューの指標とSCC間フィードバックを再計算し、SCC分断・順序崩れでBandと順序保証を取り下げる。
- Workerにはコピーを転送。runId/revisionの不一致を拒否。協調取消、1秒無応答時の再生成、30秒上限、異常終了を単体テスト。未完了の所属や架空の結果を追加しない。

## ブラウザ

Playwright 1.56.1、Brave 157.1.99.57内Chromium 157.0.8103.79、一時プロファイル・headless。本番ビルドをVite previewで配信。コマンド:

```sh
DSM_BROWSER_EXECUTABLE='/Applications/Brave Browser.app/Contents/MacOS/Brave Browser' npm run test:e2e
```

最終版はM1の5シナリオとM2の4シナリオ、合計9シナリオが全て合格（53.1秒）。途中でテストの指標名の部分一致がSCC間指標も拾ったため、metric識別子による厳密な指定へ修正した。

- 構造の実行、k変更時の木再利用、基準解との比較、α差による比較除外、保存条件の保持、所属・Sの説明、左右配色の同期。
- 逆順に入力した工程を先行順へ並べ、上下矢印とドラッグで手動変更。undo/redo・元順／解析順復帰、ビュー指標の更新、元解析指標の保持を確認。
- 入力確定の差し替え、取消・再実行、無応答Workerのフォールバック。無応答はテスト内だけでメッセージを保留して再現し、本番コードに待機フックを入れない。
- 100/200/500要素 × 密度0/1/10/100% × 両手法 × 3回、合計72解析をWorker内で計測。全て新しいワークスペースでキャッシュなし。前処理・ハッシュ・指標を含み、転送と描画を除外。目標は500要素で階層法15秒、SCC2秒。数値・環境はbenchmarks.mdへ記録。

500要素の計算最大は階層法44.8ms、SCC27.1ms。取込・初期描画の再測定も最大327.9msで目標内。記録: [benchmarks.md](benchmarks.md)、[計算の生データ](M2-benchmark-results.json)。

画面の目視確認: [構造](screenshots/M2-structure.png)、[工程・手動ビュー](screenshots/M2-process.png)。
