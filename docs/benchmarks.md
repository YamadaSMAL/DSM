## M0の実測と限界

初回の合格実行では3テストファイル・67テスト、Vitestの報告所要時間211ms。Vite本番ビルドは178ms。これらは単回の開発基盤チェックで、アプリの性能保証や繰り返しベンチマークではない。

F01〜F10の行列と、n≤7のランダム性質テストを確認した。500要素の数値行列を作成できることは境界テストで確認済み。CSV/XLSX読込、Canvas描画、階層法、SCC、MCL等は未実装のため、性能は未測定。

M1以降は仕様12に従い、n=100/200/500、密度0/1%/10%/100%で、端末・OS・ブラウザ・データ生成seed・反復数・中央値・最大値を記録する。現時点の数値から他の手法の500要素対応を推測しない。


## M1: 本番ビルドのブラウザ取込・初期描画

実施: 2026-11-16（日本時間）。上記基準端末、Node.js 26.13.1 / npm 11.20.0。Playwright 1.56.1が既存Brave 157.1.99.57を一時プロファイル・headlessで起動。エンジンはChromium 157.0.8103.79。Chrome製品での検証を意味しない。

本番ビルドをVite previewで配信。1360×1000、devicePixelRatio=1。seed=20261116のLCGで非対角の0/1を生成し、密度は生成確率。対角は0、ラベルは日本語。各条件3反復、12条件・36取込。ファイルを選択済みの状態から、検証ボタンクリック→Worker読込・検証・ハッシュ→プレビュー→自動確定→Canvas表示後のrequestAnimationFrame 2回までを計測。操作自動化の待ち時間を含み、人の確認時間は含まない。ブラウザキャッシュは反復ごとに消去しておらず、初回アプリ取得やネットワーク速度の測定ではない。
