## M0の実測と限界

初回の合格実行では3テストファイル・67テスト、Vitestの報告所要時間211ms。Vite本番ビルドは178ms。これらは単回の開発基盤チェックで、アプリの性能保証や繰り返しベンチマークではない。

F01〜F10の行列と、n≤7のランダム性質テストを確認した。500要素の数値行列を作成できることは境界テストで確認済み。CSV/XLSX読込、Canvas描画、階層法、SCC、MCL等は未実装のため、性能は未測定。

M1以降は仕様12に従い、n=100/200/500、密度0/1%/10%/100%で、端末・OS・ブラウザ・データ生成seed・反復数・中央値・最大値を記録する。現時点の数値から他の手法の500要素対応を推測しない。

## M2: 階層法とSCCの計算Worker

実施: 2026-11-16（日本時間）。上記基準端末、Node.js 26.13.1 / npm 11.20.0、Playwright 1.56.1、Brave 157.1.99.57内Chromium 157.0.8103.79（headless、一時プロファイル）。本番ビルドをVite previewで配信。viewport 1360×1000、devicePixelRatio=1。

LCG seed=20261116、非対角の0/1を独立生成。密度は生成確率。n=100/200/500、密度0/1/10/100%、各手法3反復、合計72解析。各回の入力確定でワークスペースを作り直すため、木キャッシュなし。kは既定式、α=1、τ=0、二値化なし。Worker内のrunAnalysis経過時間は前処理・ハッシュ・手法・指標・協調yieldを含み、メッセージ転送とCanvas描画を除外する。UI表示から採った値は0.1ms単位へ丸められている。
