## 乱数と操作の契約

mulberry32-v1を共用。集合は固定群スロット順、未試行リストは元index順で作り、抽出位置だけを削除する。Fisher–Yatesでshuffleし、一様選択は候補が1つでも乱数を1回使う。厳密な計算値の等値で同点判定する。

親ペアは交叉maskを全ビット生成 → 子1の全ビット変異 → 子1の合法化・MDL評価・archive更新 → 子2の全ビット変異 → 子2の合法化・MDL評価・archive更新。子1の合法化乱数の前に子2の変異乱数を先取りしない。seed=0の既知値と操作列のテストを固定する。

初期染色体はQ本全て生成してから、各個体を合法化・評価する。違法染色体の評価キャッシュは置かない。合法化したビットを親として保持する。合法化済み染色体の再評価で乱数を消費しないこともテストする。

## 目的値と行列

探索は前処理後の非対称Dで行い、入力A・原セルは変更しない。IGTA+は有向両方向の和によるTotalCost。G-IGTAはDの最大値による正規化Pと、対角を除いたS1/S2によるMDL。全零はP=0、n=1は即時終了。画面の共通C_coordは従来のmean Sで別に評価する。

TotalCost／MDLはResult.objectiveへ名前・値・版・条件を保存し、metricsにも別名で載せる。MDL係数はmdlAlpha/mdlBeta、TotalCost指数はcostExponentとし、共通C_coordのalphaと混同しない。比較キーには目的版と係数・正規化・群スロット上限を含め、異なる目的や条件の順位を分ける。複数seed統計も同じ目的値を集計する。

正のbidは通常のべき乗で計算し、対数比較へ切り替えない。overflowと正値から0へのunderflowはエラーとする。MDL正規化で正値が0へ潰れる場合も明示エラーとする。TotalCostの群外和は非対角ペアの直接加算で、近い総和の減算を避ける。MDLモデル係数は1−(alpha+beta)として非負の入力範囲を保つ。

## 実行・上限・再現

IGTA+はITC完了と提案予算到達を区別する。G-IGTAは予定世代完了と評価予算到達を区別する。安全時間上限30秒、取消、強制終了の既存契約を共用。確定した評価済み最良解を返し、取消・時間／評価／提案上限の結果は通常順位から除く。

中断結果はseedと提案／評価数まで再実行して所属・目的・初期解・カウンタを照合する。G-IGTAでは初期集団評価中、子1評価後、途中世代でも最良archiveを復元する。使用しなかった先の乱数列が一致したという主張とは区別する。

数値例は仕様§9のTotalCost=38、bid=20.25と16/3、MDL=0.6664/3.6738/14.0798を操作テストにする。加えて違法染色体・非対称重み・乱数順・保存改変・上限拒否を検証する。これらは自作参照プロファイルの検証であり、著者コード・Dustbuster等の数値入力と参照実行が揃った完全再現ではない。

性能値と対応上限は [benchmarks.md](../benchmarks.md) と [利用ガイド](../user-guide.md)。原典にない上限は実装上の制限として扱い、入力やパラメータを縮小してから実行しない。
