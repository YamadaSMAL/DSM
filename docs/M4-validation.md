# M4 検証記録

実施日: 2026-11-16（日本時間）、v0.2.0。基準環境は [benchmarks.md](benchmarks.md)。仕様書7.4・7.5、M4完了条件を対象とする。

## 実装と完了条件

| 条件 | 検証 |
| --- | --- |
| 同seed・評価予算で再現 | mulberry32-v1の固定列、seed=0、導出seedのwrap、同seed反復、JSON再実行照合 |
| 所属SAとSCC内順序SA | F07構造・F09工程、固定SCC間順序、初期解以上の最良保持、80ランダムケース |
| 差分評価 | 所属移動300ケース、順序交換300ケースを共有domain全再計算と照合 |
| MCLの列和・prune・抽出 | 50ランダム行列、零列復帰、列最大保持、同点元index、5回連続収束、反復上限 |
| 上限・取消・未収束を区別 | 実Worker取消、30秒フラグと最終評価地点、暫定結果を通常順位から除外 |
| 手法別上限 | SA500、MCL200、201要素のUI禁止とAPI拒否 |
| 複数seed比較 | 既定10逐次試行、固定予定seed、同条件のみ統計・順位、条件復元して単独再実行 |
| 元データ保持・保存 | domain指標を共有、初期／解析／手動ビューを分離。HTML/XLSX/JSONへseed・状態等を保存 |

有限予算SAのcompletedは予定探索完了を示し、最適解や数学的収束の保証ではない。MCLはアプリ独自の排他的抽出で、公式コマンドとの同一性を保証しない。判断は [decisions.md](decisions.md) D023〜D026。

## 実行した検証

- `npm run check`: 型検査、10ファイル・200テスト、本番ビルド合格。
- Braveを使った通常E2E全18シナリオ合格。既存の取込・表示・比較・オフラインHTML・XLSX/JSON・未信頼ラベル検証を含む。
- 最終調整後にM4機能4シナリオを再実行して合格。性能の実反復／評価／収束記録追加後、性能シナリオと画面3シナリオを再実行して合格。
- `npm run test:subpath`: 1シナリオ合格。リポジトリ配下URLで取込・計算・出力Worker、保存・再読込を確認。
- 対応上限・4密度・各3回、計96解析の時間と実行数を記録。全てcompleted。詳細は [性能記録](benchmarks.md#m4-saとmclの計算worker)。
- 500要素の実Worker取消は232.7ms（単回）。暫定解を保存・再読込して一致を確認。
- 取消・時間上限・温度調査途中のprefix再現、seed/batch改変拒否、巨大有限値の母標準偏差を単体検証。

画面は [構造SA](screenshots/M4-structure.png)、[工程SA](screenshots/M4-process.png)、[MCL未収束](screenshots/M4-mcl.png) を保存し、MCL画面の状態・除外理由・警告・出力とCanvasを目視確認した。

## 未確認と制限

Chrome/Edge/Firefox/Safari製品別の実機互換性、DPR=2、継続30fps、最大メモリ、GitHub Actionsと公開URLの動作は未確認。Brave結果を他環境へ一般化しない。100結果を長い探索予算で保存・復元する最悪時間は未測定で、整合性再計算が入出力の30秒上限に達する場合がある。

SAは大域最適を保証せず、MCLは最大100反復でも未収束になり得る。中断・未収束を含む結果を保持するが、強制terminateから未受信の途中状態は回収しない。IGTA系は未実装。次のM5では原典と式・手順の照合から始める。
