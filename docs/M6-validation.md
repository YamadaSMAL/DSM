# M6 検証記録

2026-11-18（日本時間）、v0.3.0。仕様7.7・7.8とM6完了条件を対象とする。M5は別の研究ゲートであり未完了。

## 実装と受入条件

| 条件 | 実装・検証 |
| --- | --- |
| IGTA系と独立した汎用GA | ga-cluster-v1、初出順染色体、一様交叉、突然変異、トーナメント・エリート、seed再現・最良保持 |
| 制約の能力宣言と未対応拒否 | GAが4種類対応。未対応のUI選択を無効化し、APIでも拒否。JSONからも同じ検証 |
| 矛盾と探索失敗の区別 | must-link同値類、cannot-link内包、規模・群数／容量の明白な矛盾を検出。予算内に解がない場合は証明済み実行不能と断定しない |
| 制約を無視しない | 初期化・修復・交叉／突然変異後は適合候補のみ評価。実行可能な制約を生成した30ケースで全条件を確認 |
| Tearingは提案 | 元Dをコピー。循環内部の最小重み・同点元indexで選択。元行列と指標を保持。最小集合の保証なしを画面と出力へ記載 |
| 元と仮想の比較 | 候補表・重み合計・仮想順序・仮想指標・第三Canvas。元SCCとBandを仮想結果へ置換しない。提案を通常順位から除外 |
| 保存・再現 | JSONの制約・候補・途中世代prefixを再実行照合。HTMLとXLSXにも条件・提案・指標を保存。改変を拒否 |

設計判断は [decisions.md](decisions.md) D028〜D030、操作は [v0.3-guide.md](v0.3-guide.md)。

## 検証内容

- `npm run check`: 型検査・12ファイル221件のテスト・本番buildが合格。
- GAの同seed再現、無制約50ランダム行列の最良保持・共有指標一致、実行可能な制約30ケース、染色体・交叉・突然変異、矛盾と未発見のメッセージ差、不正条件を検証。
- Tearingの手計算F09（元Dのフィードバック2、仮想Dは0、候補重み2）、同点順、DAG・零・単要素、上限と取消を検証。50ランダム行列で各削除辺がその時点のSCC内にあり、最終仮想グラフがDAGであることを確認。
- 完了・途中世代／途中提案・取消のJSON往復、制約と候補の改変拒否、HTML候補記載、XLSX9シートとRunConfigを検証。
- Braveの本番buildで通常E2E全22シナリオが合格（M4までの取込・表示・オフラインHTML・保存・未信頼ラベルを含む）。中断カウンタの最終調整後もM6の4機能シナリオが合格。
- `npm run test:subpath`: 1シナリオ合格。サブパスでGAとTearingも実行し、出力Workerを確認。
- 明示性能テスト1件が合格し、72解析を記録。GA36回は全て完走、Tearingは27回完走・9回上限到達で循環が残る。
- [GA画面](screenshots/M6-ga.png)、[Tearing画面](screenshots/M6-tearing.png)を保存。Tearingの候補・元／仮想指標・3つのCanvasを目視確認。
- 明示起動の性能テストは `DSM_M6_BENCHMARK=1` とREADMEのBrave環境変数で `npm run test:e2e -- tests/e2e/m6-benchmark.spec.ts`。通常のE2Eではこの長い性能テストをスキップする。

500要素GAの実Worker取消は229.6ms（単回、クリックから状態表示）。[記録](M6-cancellation-results.json)。条件別の時間測定とは別の操作応答の記録。

性能の条件別値・実反復数・実評価数・停止状態は [benchmarks.md](benchmarks.md) と生データに記録する。制約の難しさ全体や最悪ケースを網羅する性能保証ではない。

## 未確認と制限

M5のIGTA系、Chrome/Edge/Firefox/Safari製品別互換性、DPR=2、継続30fps、最大メモリ、GitHub Actions・実公開URLは未確認。GAの一般の制約実行可能性や大域最適、Tearingの最小辺集合・実際の仮定コストは保証しない。多数の制約・長時間探索・大量結果の保存では既存30秒の安全上限に達し得る。結果数・世代・提案上限を減らす必要がある。

完全な初期集団より前の取消は結果を生成しない。GAの途中世代では評価済み最良候補・実評価数を保持する。Tearingの上限・取消では循環が残る場合があり、acyclic=falseと表示する。仮想行列はアプリ上で比較でき、出力は候補辺から再構成可能だが、専用のXLSX行列シートは追加していない。
