# v0.4 IGTA原典参照プロファイル

仕様 [IGTA_ALGORITHM_SPEC.md](../../IGTA_ALGORITHM_SPEC.md) に基づく2手法を追加した。**補完規則を含む参照プロファイルであり、著者MATLABコードとの一致確認は未実施**。原典の曖昧な箇所と採用規則は [照合表](algorithms/igta-conformance.md)。取込・保存・seedの操作はv0.1〜v0.3と共通。

## 選択と条件

構造モードでIGTA+またはG-IGTAの「参照プロファイル」を選ぶ。目的値はIGTA+がTotalCost、G-IGTAがMDL。画面の調整コストC_coordはmean Sの共通評価で、目的値と同じ数値ではない。探索には非対称Dを渡し、原データを変更しない。G-IGTAは排他的クラスタで、bus・重複クラスタや構造制約を提供しない。

IGTA+はp、第二bid／無条件受理の確率の分母、提案上限を設定する。初期値はp=1、各分母10、提案100,000。bid指数4／規模指数1は固定。最高より小さい最大値を第二bidとし、全零では移動しない。現在コストの厳密改善だけ未試行リストをリセットする。新群は作らない。

G-IGTAは群スロット上限c_max、Q、G、評価上限、MDL係数、符号化を指定する。c_maxは表示された値を確認して明示的に設定する。UIの初期表示はmin(14,n)で、論文の普遍的既定値とは説明しない。APIはc_maxを省略できない。Q=36、G=36、評価1,332、alpha=0.1096／beta=0.8071、horizontalが初期値。共通C_coordのαとは別の係数。

Qは初期集団、Gは後続集団の世代数。評価上限は初期集団も含む。Q/Gを変えても評価上限を黙って書き換えない。初期Q本は全て生成してから合法化・評価する。各親ペアは交叉→子1変異・合法化・評価→子2変異・合法化・評価。合法化済み染色体を次の選択へ使い、全置換で失っても最良archiveを保持する。

## 実装上限

| 項目 | 上限・範囲 |
| --- | --- |
| 要素数 | 500（取込・各手法の入力上限） |
| IGTA+提案 | 1〜100,000 |
| TotalCost指数p | 0より大きく3以下 |
| 確率の分母 | 1〜1e9の有限数 |
| G-IGTA染色体 | c_max×n≤8,192ビット、1≤c_max≤n |
| G-IGTA Q | 偶数2〜72 |
| G-IGTA G | 0〜200 |
| G-IGTA評価 | Q以上14,472以下 |
| MDL係数 | 非負、合計1以下 |
| 計算時間 | 各試行30秒、終了待ち最大1秒 |

例えばn=500、c_max=17なら8,500ビットとなり実行を拒否する。値を16へ自動修正したり、行列から要素を削ったりしない。QやGの上限超過も同様。上限は全ての組合せで完走する保証ではない。長い予算・高密度では30秒で暫定解を返す。測定した条件・中央値・最大値・状態は [性能記録](benchmarks.md)。極端な重みでbidのべき乗が計算範囲を超える／正値から0になる場合は、暗黙の対数化や正規化をせずエラーにする。MDLの正規化で正の重みが0へ潰れる数値範囲もエラーにする。

## 結果・比較・保存

ITC終了と提案上限、予定世代完了と評価上限、取消と時間上限を区別する。予算上限や中断を「ITC収束」と表示しない。原典の大域最適性、著者の確率的結果、全近傍を調べたことを保証しない。既定10seedを逐次処理し、最良・中央値・最悪・母標準偏差を目的値で集計する。試行の全予定seedと各実行seedを保存する。

比較は同じ入力・前処理・指標版・共通α・目的の版と係数／正規化／群スロット条件に限定する。TotalCostとMDL、既存C_coordの値を一つの順位に混ぜない。共通C_coordも別の指標欄で確認できる。

HTML・XLSX・JSONに目的名／値／版／条件、実予算・停止理由・seed・初期解を保存する。解析DSMは方向を保持したDで、G-IGTA内部の正規化Pは目的値の定義として記録する。JSONは完了／予算／途中初期評価／途中世代の最良archiveを再計算して検証する。旧手法版も引き続き読める。

保存・再読込にも30秒の安全上限があり、多数結果・長時間の探索をまとめると上限に達する場合がある。自動で結果を削らずエラーにする。必要に応じて保存対象の結果数や実行予算を利用者が減らす。
